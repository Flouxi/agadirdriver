# Agadir Driver - Premium Chauffeur & Transfer Service

Official website for [AgadirDriver.com](https://agadirdriver.com), providing elite private chauffeur and airport transfer services across Morocco, including Agadir, Marrakech, Casablanca, and Essaouira.

## Features

- **Real-time Booking**: Advanced reservation flow with instant pricing calculation and interactive maps.
- **Service Pages**: Optimized SEO landing pages for major transfer routes (Taghazout, Tamraght, etc.).
- **Travel Journal**: A blog section with local travel guides and transport advice.
- **Multilingual Support**: Built-in support for multiple languages (French, English).
- **Responsive Design**: Premium, mobile-first UX inspired by modern transport platforms.
- **Safety & Reliability**: Hardened error handling and SSR safety guards for a stable production experience.

## Technical Stack

- **Framework**: [TanStack Start](https://tanstack.com/router/v1/docs/guide/start/overview) (React + Nitro)
- **Styling**: Tailwind CSS v4
- **Maps**: Leaflet
- **Validation**: Zod
- **Icons**: Lucide React

## Development

To run the project locally:

1. Clone the repository:
   ```sh
   git clone https://github.com/shgoforth/area-hostel.git
   cd area-hostel
   ```

2. Install dependencies:
   ```sh
   pnpm install
   ```

3. Start the development server:
   ```sh
   pnpm dev
   ```

4. Build for production:
   ```sh
   pnpm build
   ```

## Deployment

The project is optimized for deployment on [Vercel](https://vercel.com). All configuration is handled via `app.config.ts` and `vite.config.ts`.
